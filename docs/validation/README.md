# Milestone 4 — Validation

Four drills, each proving one of ROADMAP.md's Milestone 4 claims against data
[costkit](../../costkit) itself generated — not asserted in prose. Each report below is
regenerated by running its script (`python -m eval.run_<name>`); the pass/fail claim is enforced
by the matching test in [tests/test_validation_drills.py](../../tests/test_validation_drills.py),
which runs on every push via CI.

| Drill | Claim | Report |
| --- | --- | --- |
| Cost regression | A silent model-tier swap is caught by the anomaly detector | [cost-regression-drill.md](./cost-regression-drill.md) |
| Retry storm | Cost per outcome rises far more than total spend when failures spike | [retry-storm-drill.md](./retry-storm-drill.md) |
| Context bloat | Padded input tokens raise unit cost with no failure signature at all | [context-bloat-drill.md](./context-bloat-drill.md) |
| Attribution reconciliation | Every event's stored cost reproduces exactly from its own inputs; the grand total agrees | [attribution-reconciliation-drill.md](./attribution-reconciliation-drill.md) |

## Why four separate drills, not one

Each targets a distinct way a bill hides a real problem, per
[cost-model.md](../cost-model.md)'s waste table — and each has a different failure signature, which
is itself worth showing:

- **Retry storm** — success rate visibly drops; cost per outcome rises from more billed attempts
  per success.
- **Context bloat** — success rate stays ~100%; cost per outcome rises from token volume alone.
  A detector that only watched failure rate would miss this entirely.
- **Cost regression (model downgrade)** — neither token volume nor failure rate changes; only the
  price basis does. Only a per-feature anomaly check on cost per outcome catches it.
- **Attribution reconciliation** isn't a waste scenario at all — it's the check that the other
  three drills' numbers can be trusted in the first place.

## Reproducing these

```bash
python -m eval.run_cost_regression_drill
python -m eval.run_retry_storm_drill
python -m eval.run_context_bloat_drill
python -m eval.run_attribution_reconciliation
```

Each is deterministic (seeded) and regenerates its own report in this directory. `make validate`
runs all four plus the enforced test suite.
